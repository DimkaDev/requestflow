Quickstart Guide

Learn how to connect your first application to FlowTrace, emit live spans via high-speed UDP or HTTP, and watch your requests travel in real time across the interactive topology canvas.

bolt
Zero-latency guarantee <0.2ms overhead

FlowTrace uses non-blocking asynchronous memory buffers and fire-and-forget UDP packets (port 8125). Emitting spans adds negligible runtime overhead to your request cycle and will never block upstream HTTP threads.

1

Install the client SDK

FlowTrace maintains zero-dependency tracing packages across major runtimes. Select your stack below to download the official agent. 

# Using npm
npm install @flowtrace/node

# Alternatively via pnpm or yarn
pnpm add @flowtrace/node
yarn add @flowtrace/node
2

Initialize the FlowTrace tracer

Obtain your project API key from Project Settings > API Keys. Instantiate the tracer instance near your process bootstrap logic.

tracer.ts 
import { initTracer } from '@flowtrace/node';

export const tracer = initTracer({
  apiKey: process.env.FLOWTRACE_API_KEY, // ft_live_7x90b...
  service: 'checkout-api',
  cluster: 'us-east-prod-04',
  endpoint: 'udp://127.0.0.1:8125', // or https://ingest.flowtrace.live/v1
  sampleRate: 1.0, // 100% trace sampling for local dev
});
3

Trace your first request execution

Wrap sensitive routes or downstream call chains with explicit spans. Attributes set on the span are automatically indexed into searchable topological nodes.

code server.ts 
// In your HTTP request handler or background worker
app.post('/api/checkout', async (req, res) => {
  const span = tracer.startSpan('checkout.process_order', {
    attributes: {
      'customer.tier': req.user.tier,
      'cart.total': req.body.amount,
      'payment.provider': 'stripe'
    }
  });

  try {
    const result = await processPayment(req.body);
    span.setStatus({ code: 'OK' });
    return res.json({ success: true, orderId: result.id });
  } catch (err) {
    span.recordException(err);
    span.setStatus({ code: 'ERROR', message: err.message });
    throw err;
  } finally {
    span.end(); // Flushes to local daemon in <0.05ms
  }
});
tips_and_updates
Pro Tip — Topology Auto-Discovery

Nodes and edges are automatically provisioned on your canvas the moment the first checkpoint arrives. You don't need to manually design or upload architecture diagrams beforehand.

4

Verify on the live canvas

Send a test payload to your application. The FlowTrace ingest engine recognizes new telemetry streams within milliseconds.
